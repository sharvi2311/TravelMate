# 🚀 Travel Route Intelligence Platform Prototype

A local travel booking prototype featuring AI custom trip generation, dynamic pricing, and intelligent route optimization.

## ⚙️ Prerequisites
- Python 3.8+ installed
- A modern web browser (Chrome/Edge/Firefox)

## 🛠️ How to Run Locally

### Step 1: Install Dependencies
Open your terminal/command prompt in this folder and run:
```bash
pip install -r requirements.txt


### Step 2: Run FastAPI
Open your terminal/command prompt in this folder and run:
```bash
python main.py


### Step 3: Open the FrontEnd
Open new terminal/command prompt in this folder and run:
```bash
python -m http.server 3000

## Open your browser and go to: http://localhost:3000
